# Ziyu (Peter) Jiang — Academic Website

This is a Jekyll / Minimal Mistakes website for an economics PhD candidate academic profile.

## Domain

The custom domain is set in `CNAME`:

```text
ziyu-jiang.com
```

The site URL is also set in `_config.yml`:

```yaml
url: "https://ziyu-jiang.com"
baseurl: ""
```

## Most important files to edit

- `index.md` — homepage bio, fields, featured paper, job-market sentence.
- `_pages/research.md` — papers, abstracts, links, and future job-market-paper label.
- `_pages/cv.md` — web CV page.
- `assets/files/ziyu_jiang_cv.pdf` — downloadable PDF CV.
- `_pages/contact.md` — contact information.
- `_data/navigation.yml` — top navigation.
- `_config.yml` — site title, author metadata, email, and domain metadata.
- `CNAME` — custom domain for GitHub Pages. Do not delete it.

## Before publishing for the job market

1. Add the job-market sentence to `index.md` only when ready.
2. Add the job market paper PDF to `assets/files/`.
3. Put the job market paper first on `_pages/research.md` under a `Job Market Paper` heading.
4. Link the job market paper from the homepage.
5. Test all links in a private/incognito browser.
